## 🎲 核心游戏规则
1.  庄闲赔付规则**：庄闲平局无输赢，闲9点不翻倍，闲家有中都全额赔付；开奖以微信群红包为准，结果从下往上算，下注群仅提供下注通道。
2.  **下注生效规则**：刷注入图后输赢无争议，出图后不支持无效；分不足系统自动默认，下注格式错误、没入图的，输赢以群管理截图为准，无认注、无效当局全部作废。
3.  **投注门槛**：上庄50000元起标，上不封顶；闲家50元起注，无上限。
4.  **定庄规则**：出庄时，庄摇1个骰子、机器人摇1个骰子，谁标庄谁摇，定庄门，续庄可换人摇骰子。
5.  **红包规则**：发包金额/数量错误一律无效重发；视频发包出现卡包、超时、缺记录、双包，以包手发的第一个红包为准，输赢不纠结。
6.  **抢包秩序**：庄闲均可抢包，顶包/恶意捣乱者警告一次，再犯直接移出群聊。
7.  **系统异常处理**：平台更新导致机器人漏注，以机器人截图为准；机器人庄门出错，以骰子结果为准，输赢不纠结。
8.  **上分规则**：上分以群财务收款到账为准，必须先上分后下注；转账前确认收款账户，认准群财务，勿随意改名，被骗/转错本群不负责。
9.  **开关机时间**：以群公告为准，最终解释权归本群所有。（以上规则后台可随时修改）

二、角色权限与数据层级说明

系统包含以下角色，其中“股东”为独立只读角色，不参与下钻链路；其余角色按“管理员 → 群主 → 总代 → 代理 → 会员”逐级下钻，最终末端为会员订单明细。

1. 股东角色（新增，独立权限）
该角色不归属于下级层级树，拥有全局只读权限，可查看所有层级的报表数据

2. 管理员层级（正常下钻链路起点）
展示所有群主列表。每个群主显示：该群主的流水、输赢、佣金，以及该群主下辖的总代数量。点击某个群主，进入该群主的下一层级。

3. 群主层级
展示该群主下属的所有总代列表。每个总代显示：该总代的流水、输赢、佣金，以及该总代下辖的代理数量。点击某个总代，进入下一层级。

4. 总代层级
展示该总代下属的所有代理列表。每个代理显示：该代理的流水、输赢、佣金，以及该代理下辖的会员数量。点击某个代理，进入下一层级。

5. 代理层级
展示该代理下属的所有会员列表。每个会员显示：该会员的流水、输赢、佣金。点击某个会员，进入该会员的订单明细。

6. 会员层级（末端）
展示该会员的所有订单明细，包含订单编号、时间、游戏类型、投注金额、盈亏、佣金、状态等字段。支持分页和排序，此为最底层数据，无法继续下钻。

补充说明：

· “下级数量”列仅在当前层级显示（例如管理员看群主时显示总代数量），进入下一层后不再重复显示该数量，而是直接展示该层下级的列表及其自身指标。
· 所有“流水、输赢、佣金”均为当前所选时间范围内的汇总值。
· 股东角色因不参与下钻，其报表展示方式为全量汇总视图，而非逐级列表。

三、交互与展示要求

· 面包屑导航：页面顶部显示当前层级路径（如“管理员 > 群主A > 总代B”），点击任意上级可快速返回该层级。股东角色无需面包屑导航，仅展示报表总览页。
· 表格动态适应：各层级使用统一风格的表格，但表头根据层级自动调整列数（不同层级列数不同）。
· 数据刷新：切换时间筛选或进行下钻操作时，当前页面数据自动重新加载。
· 权限控制：各角色只能查看自己权限范围内的数据。股东可查看全量报表（只读），管理员可查看所有下级数据，其余角色仅可查看自身直属下级数据。
